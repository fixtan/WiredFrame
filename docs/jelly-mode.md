# ゼリーモード

ぷにぷにしたゼリーが跳ね回り、同じ色どうしがぶつかると合体して大きく育つ。いちばん大きく育つと「臨界点」の演出があり、そのあとはぶつかるたびに半分に分かれて小さくなり、また育つ。これを繰り返す。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/modes/jelly/JellyWorld.ts` | 物理。three.js に依存しない（Node でも動く）。60Hz 固定刻み |
| `src/modes/JellyMode.ts` | Canvas2D に描いて、全画面の板のテクスチャとして貼る。パラメータを物理へ渡す |
| `src/modes/params.ts` の `JELLY_PARAMS` | 設定パネルの「詳細な調整」に出るスライダー |

## 動きの流れ

1. **成長（grow）**: ゼリーの面積の合計が `fill`（箱の何割か）になるまで、小さいゼリーを足す。同じ段のゼリーが重なる（点が 5 個以上入りこむ）と合体して 1 段大きくなる。生まれてから `mergeDelay` 秒は合体しない。
2. **臨界点**: いちばん大きい段（9 段目）ができると演出（光る・輪が広がる・揺れる・脈打つ）。`evSec` 秒。
3. **分裂（split）**: ぶつかったゼリーが、長い軸の向きで 1 段小さい 2 個に分かれる（面積は保つ）。生まれてから `splitCool` 秒は分裂しない。全部が下限の段（`minCls`）以下になったら 1 に戻る。

## 物理の要点

- 1 個 = 点の輪。PBD + Verlet、1 フレームを 6 サブステップ。拘束は辺の長さ・面積（圧力）・1 つ飛ばしの距離・形の保持。
- 衝突は「点が相手の内側に入ったら、いちばん近い辺から押し出す」。点が 3 個以上入りこんだら `separate` でゼリーごと離す（からまって離れなくなるのを防ぐ）。
- 重力なし。全体の速さを `speed` の 0.7〜1.5 倍に保つので止まらない。
- 周長と面積を両方固定すると円しか残らない（等周不等式）ので、周長は √(面積比) で縮め、形は弱く保つ。

## 画面サイズへの対応

- 箱の高さは 700 固定。幅は画面の縦横比で決まる。横長の画面ほど、ゼリーの数が増える。
- いちばん大きい段が、箱の短辺の 34% を超えないよう、大きさの倍率に上限を掛ける（縦置きモニターでも収まる）。
- 画面の縦横比が変わる、または「ゼリーの大きさ」を変えると、初めからやり直す。
- 描画は `quality` で解像度を下げられる（高さ 1440 が上限）。物理が進んだフレームだけ描き直してテクスチャを送る。

## 調整パラメータ

`fill` 量 / `sizeScale` 大きさ / `speed` 速さ / `soft` やわらかさ / `press` ふくらみ / `amoeba` いびつさ / `mergeDelay` 合体の待ち / `splitCool` 分裂の待ち / `minCls` 分裂の下限の段 / `evSec` 演出の長さ / `splitCap` 個数の上限 / `quality` 解像度。

重いときは、`splitCap` と `minCls`（上げる）、`quality`（下げる）、`fill`（下げる）の順に調整する。

## 既知の限界

- ごくまれに輪郭が一時的に折れる（ほとんどは数十フレームで戻る）。原因は未特定。
- 衝突は「点と多角形」の方式なので、詰め込むと弱い。小さな円の輪＋内圧の方式への作り直しが根本対策（未実装）。
- 実機での負荷（複数モニター同時）は未計測。
