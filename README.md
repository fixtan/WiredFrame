# WiredFrame

画像フォルダの写真をタイル状に並べて動かす、マルチモニター対応のスクリーンセーバー（Windows 専用）。
Tauri v2（Rust）+ Vite + TypeScript + Three.js 製。

## できること

- タスクトレイに常駐。ホットキー、トレイメニュー、またはキー・マウスの無操作で起動し、**ESC で終了**
- モニターごとに独立した画面。画像フォルダ・表示パターン・タイルの大きさ・列数/行数・背景を、モニターごとに設定できる
- 名前を付けた画像フォルダのリストを作り、モニターごとに選べる（リストは全モニター共通）
- ケーブルの抜き差しやモニター構成の変更に追従して、自動で再展開
- 列数・行数に合わせてカメラを自動調整（縦置きモニターにも対応）
- Windows ログイン時の自動起動（任意）

## 使い方

1. 起動するとタスクトレイに常駐します（起動しただけでは何も表示しません）。
2. トレイのアイコンを右クリック →「設定」。全モニターにセーバーが映り、モニターごとの設定パネルが開きます（変更はその場でプレビューされます）。
3. 「画像フォルダの一覧」で「＋ フォルダを追加」し、名前とパスを登録します。「共通の既定」を選び、必要なら各モニターで別のフォルダを選びます。
4. 設定が済んだら、トレイの「スクリーンセーバーを起動」、設定したホットキー、または無操作の自動起動で動かします。**ESC** で終了します。

### トレイメニュー

| 項目 | 内容 |
| --- | --- |
| スクリーンセーバーを起動 | 今すぐ起動 |
| 設定 | 設定モードで起動（全モニターにパネル付きで映す） |
| モニターを再展開 | サブモニターの画面を開き直す |
| デバッグ表示 | ログのオーバーレイ（F2 でも切替） |
| 終了 | アプリを終了 |

### 設定項目

- **共通（設定パネルは main のものだけ）**: 画像フォルダの一覧と共通の既定、起動ホットキー、無操作で自動起動（ON/OFF と分数）、Windows ログイン時の自動起動、マルチモニター連動
- **モニターごと**: 使う画像フォルダ、切り替え間隔、表示パターン（ランダム/固定）、タイルの大きさと間隔、列数・行数・自動フィット、背景色・背景画像

設定はブラウザ部分の保存領域（localStorage）に入ります。

## 動作の注意

- 無操作の検知は Windows のシステム全体の入力時刻を見ています。動画再生中でも、入力がなければ起動します。
- 無操作で自動起動したセーバーは、どのキー・マウス操作でも終了します。手動で起動したセーバーは ESC のみで終了します。
- 画像フォルダが未登録・読めないときは、代わりの画像（インターネット上）を使います。オフラインだと灰色のタイルになります。
- 他のアプリとホットキーが重なると登録に失敗します。理由は設定パネルに表示されます。

## 開発

```
npm install
npm run tauri dev      # 開発起動
npm run tauri build    # インストーラー作成（NSIS）
```

必要なもの: Node.js、Rust（edition 2024 対応版）、WebView2（Windows 11 は標準）。
設計メモや確認手順は `docs/` にあります。

- `docs/multi-monitor-design.md` マルチモニターの設計
- `docs/roadmap-v0.1.0.md` v0.1.0 までの方針
- `docs/debug-tools.md` デバッグ表示と動作確認の手順
